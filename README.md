# My Reading Submissions

This is your own private log of interactive-reading scores for the Data
Analytics Fellowship. It's a template — you're looking at your own copy of
it, not a shared repo everyone submits into.

## One-time setup

1. You're here because you clicked **"Use this template"** on the template
   repo and created your own copy. If you haven't done that yet, go back and
   do it now — don't submit readings into the template itself.
2. Rename your copy if you want (the default name is fine), but if you do
   rename it, use exactly **`reading-submissions`** unless you plan to type
   a custom repo name into every single reading you do — the reading page
   defaults to that name so most people never have to type it.
3. **Settings → Collaborators → Add people** → add your instructor
   (Angelica) with **Read** access. Read is enough for her to see your
   submissions; she doesn't need write access to your repo.
4. Keep this repo **private** (it should already be, since it was created
   from a private template) — that's what keeps your answers and scores
   visible only to you and your instructor, not the rest of the cohort.

## How submitting works

On a reading, after you enter your GitHub username, "Submit for credit"
opens a **pre-filled GitHub Issue right here, in your own repo** — you
review it and click "Submit new issue" yourself, the same way you'd open
any GitHub issue. No token, no password, nothing pasted in.

Opening that issue also counts on your real GitHub contribution graph,
same as a commit or a PR would.

## What your instructor sees

Nothing lives here that isn't already visible to any collaborator with
Read access — which is just you and your instructor. Your instructor
periodically pulls scores from everyone's repo into a private gradebook;
nothing here is shared with classmates.

You get 2 submission attempts per reading; your best score is what counts.
